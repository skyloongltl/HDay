# 健身计数 App 低保真原型设计说明

## 1. 文档信息

- 设计阶段：低保真原型
- 目标平台：Android
- 需求依据：`docs/fitness-counter-app-prd.md`
- 设计目标：确定首版信息架构、核心页面布局、训练闭环与关键状态，不包含视觉品牌、动效和像素级规范。

## 2. 设计原则

1. **训练行动优先**：用户打开 App 后应立即看到今日任务和开始训练入口。
2. **训练中操作直接**：高频操作固定在可触达位置，避免藏入多层菜单。
3. **状态清晰**：训练、休息、恢复和结束使用明确的页面状态。
4. **计划与记录分离**：计划是模板，开始训练后使用独立快照。
5. **复杂功能分场景呈现**：计划查询与计划编辑使用不同布局，各自服务于浏览和操作。
6. **中断可恢复**：关键操作即时持久化，计时不依赖页面持续前台运行。

## 3. 信息架构

### 3.1 主导航

底部导航固定为四项：

1. 今日
2. 计划
3. 日历
4. 动作

设置不占用底部导航位置，从今日首页右上角进入。

### 3.2 沉浸式流程

以下页面隐藏底部导航，避免训练过程中误触离开：

- 训练前清单
- 训练执行
- 休息状态
- 结束确认
- 训练总结

### 3.3 页面结构

#### 今日模块

- 今日首页
- 全部计划休息日状态
- 未结束训练状态
- 今日训练来源与合并结果

#### 计划模块

- 计划列表
- 计划查询总览
- 计划基础信息编辑
- 周期日编辑
- 计划动作编辑
- 训练组编辑与批量建组

#### 日历与历史模块

- 月历
- 日期详情
- 单次训练历史详情
- 历史数据修正
- 删除训练记录确认

#### 动作模块

- 动作库
- 动作搜索
- 最近使用动作
- 动作新建与编辑
- 动作选择器

#### 设置模块

- 默认重量单位
- 默认目标休息时长
- 休息提醒
- 震动提醒
- 通知权限状态
- 一周起始日
- 保持屏幕常亮

## 4. 核心布局决策

### 4.1 今日首页：行动优先布局

首页采用“今日行动型”布局，信息顺序如下：

1. 当前日期与设置入口
2. 今日训练主卡片
3. 开始今日训练主按钮
4. 自由训练次按钮
5. 累计、本周和本月健身天数
6. 今日动作清单摘要
7. 各启用计划当日周期日与来源信息

今日主卡片显示：

- 今日是否已有训练记录
- 合并后动作数与总组数
- 来源计划数量及周期日
- 预计训练时长
- 全部计划是否均为休息日

存在未结束训练时，主卡片替换为恢复卡片，显示：

- 继续训练
- 当前动作与训练组
- 已训练时长
- 已完成组数与总组数
- 结束并保存入口

### 4.2 计划查询：纵向折叠列表

计划查询总览采用纵向折叠布局，用于整体浏览周期内容。

每个周期日显示：

- 周期日序号与名称
- 训练日或休息日
- 动作数与总组数
- 展开或收起状态

展开训练日后显示其动作清单与组数。该页面用于查询和总览，不承担密集编辑。

### 4.3 计划编辑：横向周期日标签

编辑计划时采用横向周期日标签布局：

- 顶部显示 D1 至 DN 标签
- 当前周期日使用高对比选中状态
- 长周期支持按序号跳转和搜索周期日
- 标签区域支持横向滚动
- 当前周期日下方编辑名称、训练日类型、动作和训练组

周期日操作包括：

- 设为训练日或休息日
- 复制当前周期日
- 添加、删除、复制和排序动作
- 添加、删除、复制和排序训练组
- 修改动作备注和目标休息时长

休息日不显示动作编辑区域。

### 4.4 训练执行：完整清单布局

训练状态采用完整清单布局，以支持用户在训练中跳转、调整和查看整体进度。

顶栏固定显示：

- 返回入口
- 总训练时长
- 结束按钮

内容区显示：

- 已完成组数与总组数
- 整体进度条
- 按顺序排列的训练动作
- 每个动作下的所有训练组
- 各组状态、计划数据和实际数据
- 当前选中组的高对比状态

底部固定操作区根据选中组状态显示：

- 开始本组
- 完成本组
- 跳过本组
- 修改实际重量与次数
- 添加训练组
- 查看更多临时调整操作

未完成动作允许重排。已完成内容保持原位置和状态，不参与重排。

### 4.5 休息状态：独立状态页

完成一组后立即切换到休息状态页。页面突出显示：

- 实际休息累计时间
- 目标休息时长
- 距离目标时间的倒计时
- 下一组动作、重量、次数和组序号
- 后续一组的简要预览

底部固定操作：

- 结束休息并开始下一组
- 选择其他未完成组

达到目标时间时震动或发送本地通知，但不自动开始下一组。超过目标后继续累计实际休息时间。

休息页顶栏同样固定显示“结束”按钮。

## 5. 核心训练流程

```text
今日首页
  → 训练前清单
  → 确认并创建训练快照
  → 开始总计时
  → 训练完整清单
  ⇄ 休息状态
  → 结束确认
  → 训练总结
  → 保存历史记录
```

### 5.1 今日训练

1. 系统计算所有启用且有效计划的当日周期日。
2. 排除当日休息的计划。
3. 按计划优先级和默认顺序合并动作。
4. 首页展示合并结果。
5. 用户进入训练前清单。
6. 用户确认后创建独立快照并开始总计时。

### 5.2 训练前清单

训练前允许：

- 调整动作或训练组顺序
- 修改重量和次数
- 增删动作
- 增删训练组

页面明确提示：所有调整只影响本次训练，不修改原计划。

### 5.3 训练与休息切换

1. 用户在完整清单中选择未开始组。
2. 点击“开始本组”，状态变为进行中并记录开始时间。
3. 点击“完成本组”，记录实际数据、完成时间和单组用时。
4. 系统立即进入休息状态并开始累计实际休息时间。
5. 用户开始下一有效组时，休息结束；休息时长记录到该组的“开始前休息时长”。
6. 页面返回完整训练清单并将新组标记为进行中。

### 5.4 自由训练

自由训练从首页进入空白训练前清单。用户先添加动作和训练组，确认后复用与今日训练相同的快照、计时和保存流程。

### 5.5 中断恢复

App 启动时检测未结束训练。存在未结束训练时：首页优先展示恢复卡片。

恢复内容包括：

- 当前动作与训练组
- 各组状态与实际数据
- 总训练时长
- 当前组单组计时
- 休息累计时间
- 临时添加和调整的内容

训练或休息时长通过持久化绝对时间戳重新计算，不依赖进程持续运行。

## 6. 随时结束训练

### 6.1 固定入口

训练完整清单和休息状态页右上角固定显示“结束”按钮。该入口不可隐藏在更多菜单中。

### 6.2 结束确认面板

点击“结束”后，从底部弹出确认面板，显示：

- 当前总训练时长
- 已完成动作数
- 已完成组数
- 剩余组数
- 当前训练是否满足有效保存条件

提供三个操作：

1. **结束并保存已完成内容**
2. **返回继续训练**
3. **放弃本次训练**

### 6.3 提前结束规则

选择“结束并保存已完成内容”时：

- 已完成组保留原始记录
- 当前正在进行的组停止计时并标记为跳过
- 所有未开始组标记为跳过
- 若当前处于休息状态，立即结束本次休息记录
- 进入训练总结页并允许填写备注

至少完成一组时，场次可以保存并计入健身日。未完成任何组时，不生成有效训练记录，只允许返回继续或放弃本次训练。

“放弃本次训练”属于破坏性操作，必须再次确认，确认后删除本次未完成场次及其快照。

## 7. 训练结束与总结

结束训练后显示：

- 总训练时长
- 已完成动作数
- 已完成组数
- 已跳过组数
- 未完成组数
- 训练备注

如果用户通过正常结束入口且仍有未完成组，保存前统一将其标记为跳过。

用户可以：

- 保存训练
- 返回继续训练
- 放弃本次训练

保存成功后进入当日历史详情。

## 8. 日历与历史布局

### 8.1 月历标记

月历区分训练结果和计划状态：

- 实心主要标记：存在有效训练记录
- 描边次要标记：有计划但未训练
- 休息样式：所有有效计划均为休息日
- 特殊状态：存在未结束训练

同一日期可同时显示主要标记和次要状态，但训练结果的视觉权重更高。

### 8.2 日期详情

点击日期后显示：

- 当天训练状态
- 当天场次数量
- 每个场次的起止时间
- 总训练时长
- 来源计划和周期日
- 完成组数与总组数

同日多个场次按开始时间排列。

### 8.3 历史详情

历史详情按动作折叠展示，每组包含：

- 计划重量、次数和单位快照
- 实际重量与次数
- 组状态
- 开始和完成时间
- 单组用时
- 开始前休息时长
- 是否临时添加

允许修改训练备注、实际重量和实际次数。删除记录必须二次确认。

## 9. 动作库布局

动作库页面包含：

1. 搜索框
2. 最近使用动作
3. 全部动作列表
4. 新建动作按钮

动作条目显示名称、默认重量单位和备注摘要。动作选择器复用该列表结构，支持单选或连续添加。

默认不允许完全同名动作。重量单位至少支持 kg、lb、自重和无重量。

## 10. 状态与反馈

### 10.1 训练组状态

- 未开始：空心状态图标
- 进行中：高对比边框和计时提示
- 已完成：实心完成图标
- 已跳过：弱化显示并标注跳过

### 10.2 自动保存反馈

关键操作完成后即时保存。保存成功默认不弹出打断操作的提示，只在顶栏短暂显示轻量状态。保存失败时保留当前界面数据并明确提示重试。

自动保存时机包括：

- 开始训练
- 开始一组
- 完成一组
- 跳过一组
- 修改实际数据
- 增删或排序动作和训练组
- 结束训练

### 10.3 时间异常

检测到负数或明显异常跨度时：

- 不显示或保存负数时长
- 暂停依赖异常时间的自动计算
- 提示用户确认系统时间后继续
- 保留最近一次有效保存的数据

## 11. 原型验收要点

1. 首页主按钮可以直接进入今日训练准备页。
2. 存在未结束训练时，首页优先显示恢复入口。
3. 多计划合并来源和周期日可被用户查看。
4. 计划查询使用纵向折叠布局，计划编辑使用横向周期日标签。
5. 训练执行页完整展示动作和组，并允许选择任一未完成组。
6. 完成组后自动进入独立休息状态。
7. 训练和休息页右上角始终可见“结束”按钮。
8. 提前结束可保存已完成内容，并将当前及剩余组标记为跳过。
9. 自由训练与计划训练复用相同执行流程。
10. 锁屏、切换应用或进程回收后可以恢复训练和计时。
11. 日历能够区分实际训练记录与计划状态。
12. 历史详情展示训练快照，不受原计划后续修改影响。

## 12. 后续设计阶段

低保真方案确认后，后续可依次进行：

1. 将页面转换为可点击交互原型。
2. 补充页面状态矩阵和弹窗规范。
3. 定义 Android 视觉系统、色彩、字号、间距与组件规范。
4. 针对单手操作和训练场景进行可用性验证。
5. 根据验证结果调整信息密度与触控区域。

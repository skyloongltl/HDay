## Fixture and measurement contract

- **S:** isolated in-memory SQLite, date 2026-12-15, UTC clock 08:00. Typed repositories save catalog x1/x2, enabled plan p1/revision r1 (seven days, D1 one prescribed set), and history-a (one completed 40kg × 8 set and one skipped set). Historical source labels are immutable snapshots. Catalog names/metadata are test-only values.
- **L:** S plus a 365-day revision, long Chinese plan name, and eight long Chinese exercise entries on D1. Later days are empty. No production data seeding.
- **W:** a typed WorkoutMachine transition sequence persisted by the existing real SQLite workout harness. Every phase gets its own database and one unfinished session. The requested viewport is restored after the established harness's 390px default and explicitly asserted.
- Settings uses a test-owned known-granted `RestEffectsStatus` to make the host image deterministic; actual settings persistence and controllers remain real. Loading/error wrap only TodayRepository's read boundary; successful retry executes the real SQLite repository.
- Viewport height is 844 logical pixels, DPR 1. Noto Sans SC (`C:/Windows/Fonts/NotoSansSC-VF.ttf`) and bundled MaterialIcons are loaded for route, responsive and golden tests.
- **B:** every named mandatory target must exist exactly once; shortest side >=48; left/top >=0; right <= tested width; bottom <=844; no render/overflow exception. Targets are measured after individual `ensureVisible` calls, so rects for different scroll positions are not simultaneous. Every rect is `[left,top,width,height]` in logical pixels, rounded to two decimals for display; the retained JSON log has full precision. This is an explicit mandatory-target inventory, not an assertion about unnamed controls.
- **C:** the actual screen theme must equal React page/fog `#F4F7FA`, hero/deepBlue `#19344C`, primary/coral `#C76F62`, outline `#DFE7EC`. This checks tokens; visual inspection checks their use, card hierarchy, typography, wrapping and borders.
- Each matrix row independently records width and scale. Only retained PNG pairs are marked visually inspected. The other three pairs per state have host layout/bounds evidence and explicitly remain screenshot-unverified.

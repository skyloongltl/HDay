# 健身计数 App UI 设计规格

## 1. 目标与范围

本规格将已确认的低保真原型转化为 Android 首版可落地的 Flutter UI 视觉系统。首版保留三套完整主题，所有主题共享页面结构、业务组件、交互位置和状态语义，仅切换视觉令牌与少量反馈动效。

设计依据：

- `docs/fitness-counter-app-prd.md`
- `docs/fitness-counter-app-prototype-design.md`
- `.superpowers/brainstorm/883-1789215497/content/three-theme-key-screens-v4.html`

本规格覆盖主题系统、核心视觉令牌、今日首页、训练执行页、休息页、设置中的主题切换及 Flutter 设计边界。其他页面沿用同一组件语言，并在实施阶段按原型说明补齐。

## 2. 已确认决策

1. 保留 A、B、C 三套完整主题。
2. A「呼吸节拍」为首次启动和未设置用户的默认主题。
3. A 的主操作强调色采用灰调珊瑚 `#C76F62`，不使用原高饱和橙色。
4. 三套主题共享布局、导航、文案、触控区域和状态含义。
5. 主题可以切换颜色、字体、圆角、描边、阴影和少量反馈动效。
6. 设置中提供主题实时缩略预览，选择后立即全局生效并保存到本地。
7. 当前设计稿中的整体字体尺寸作为实现基准，相比早期稿统一放大约 15%。
8. 训练与休息页右上角固定显示紧凑型“结束”按钮。
9. “今日 / 训练 / 休息”标签与各页左侧顶部辅助文字对齐，不与“结束”按钮重叠。

## 3. 视觉原则

### 3.1 训练行动优先

今日首页先呈现今日训练与开始入口；统计和动作摘要作为辅助。训练执行页的主操作固定在底部可触达区域，不因主题变化移动。

### 3.2 状态优先于装饰

颜色、形状和动效首先表达未开始、进行中、已完成、已跳过、休息中和异常状态。主题可以改变表现形式，但不能改变状态含义。

### 3.3 每套主题只保留一个记忆点

- A：灰调珊瑚行动色与薄荷呼吸状态。
- B：训练日志式硬边、错位阴影和完成盖章反馈。
- C：腕表式计时层级和克制的荧光状态色。

不增加与业务无关的渐变、漂浮装饰或持续动画。

### 3.4 训练场景可读性

训练时间、休息时间、当前组、实际重量和次数必须在健身房低注意力场景中清晰可读。不能仅依赖颜色区分状态；同时使用图标、文字或形状。

## 4. 共享布局与组件边界

三套主题必须复用同一组 Flutter Widget。主题切换不能创建三套页面实现。

共享内容：

- 页面信息架构与导航路径
- SafeArea、顶部栏和底部操作区位置
- 卡片、列表、训练组和表单的内容结构
- 触控区域尺寸
- 训练状态机及状态文案
- 页面滚动、弹窗和确认流程
- 无障碍语义与焦点顺序

可由主题切换的内容：

- 语义颜色
- 字体家族及字重映射
- 圆角、描边、阴影
- 图标容器形状
- 进度与计时器视觉
- 完成组等用户触发反馈动效

不得由主题切换的内容：

- 按钮位置与功能
- 页面信息顺序
- 状态含义
- 数据格式和单位语义
- 可点击区域大小
- 破坏性操作确认级别

## 5. 字体与字号

### 5.1 字体角色

- A「呼吸节拍」：MiSans；不可用时回退到 `Noto Sans SC` 和系统无衬线字体。
- B「训练贴纸册」：展示标题可使用得意黑，正文和数据使用 MiSans；得意黑缺失时标题同样回退到 MiSans。
- C「夜训仪表」：正文使用 HarmonyOS Sans SC；计时数字使用 Roboto Condensed；缺失时分别回退到 `Noto Sans SC` 和系统窄体数字样式。

字体资源必须随应用打包，不依赖运行时网络下载。

### 5.2 核心字号基准

以下为 Flutter 逻辑像素基准，并允许系统字体缩放：

- 页面主标题：23
- 今日训练卡标题：21
- 顶部训练时长：20
- 休息主计时：40
- 主按钮：14
- 动作名称：12
- 训练组数据：11
- 辅助说明：10
- 顶部页面标签：10
- 紧凑型结束按钮：12

字重与字体可随主题改变，但同一语义层级的布局占位保持兼容。系统字体缩放达到 1.3 倍时不得截断关键训练数据；更高倍率允许页面滚动或内容换行。

## 6. 三套主题令牌

### 6.1 A：呼吸节拍（默认）

颜色：

- 深海蓝：`#19344C`，用于今日训练主卡和深色信息承载区。
- 灰调珊瑚：`#C76F62`，用于主操作、主要进度和关键行动强调。
- 呼吸薄荷：`#62E6CA`，用于进行中、恢复和正向状态提示。
- 雾白背景：`#F4F7FA`。
- 主文字：`#142A3A`。
- 卡片描边：`#DFE7EC`。

形状：

- 主卡片圆角 20–24。
- 普通卡片圆角 12–16。
- 按钮圆角 12–16。
- 阴影轻且扩散，不重复用于每个列表项。

动效：

- 进行中状态允许一次缓慢呼吸脉冲。
- 完成操作使用短促缩放与颜色确认，不持续循环。

### 6.2 B：训练贴纸册

颜色：

- 训练黄：`#FFDF3D`。
- 记录紫：`#6956DF`。
- 盖章红：`#FF655F`。
- 器械薄荷：`#8CE6CF`。
- 墨色：`#25231E`。
- 纸张背景：`#FFF7D8`。

形状：

- 卡片圆角 6–10。
- 主要容器使用 2px 墨色描边。
- 关键卡片和按钮允许 2–5px 单方向错位硬阴影。
- 不为所有小元素添加阴影，避免视觉噪声。

动效：

- 完成一组触发一次盖章式缩放与轻微旋转回正。
- 页面进入不使用逐卡片上浮动画。

### 6.3 C：夜训仪表

颜色：

- 夜幕背景：`#131720`。
- 仪表表面：`#1D222C`。
- 操作蓝：`#5D85FF`。
- 状态荧光：`#C8FF5A`。
- 主文字：`#EDF2F7`。
- 描边：`#303845`。

形状：

- 主卡片圆角 16–20。
- 普通卡片圆角 10–14。
- 阴影以低透明度内外层级为主，不使用大面积霓虹光晕。

动效：

- 荧光色只用于进行中、完成和计时到达目标等状态。
- 休息计时环允许平滑进度变化，不增加背景运动。

## 7. 页面设计

### 7.1 今日首页

固定信息顺序：

1. 系统状态栏。
2. 左侧日期辅助文字，右侧“今日”页面标签。
3. 页面主标题。
4. 今日训练主卡。
5. 开始今日训练主按钮。
6. 累计、本周、本月训练天数。
7. 今日动作列表摘要。
8. 四项底部导航。

对齐规则：

- “今日”标签与左侧日期文字使用相同字号和顶部基线。
- 标签仅作页面定位，不增加胶囊底色或额外装饰。
- A/B/C 主题保持同一位置和占位。

必须扩展的状态：

- 正常今日训练
- 多计划合并
- 全部计划休息日
- 无有效计划
- 今日已有训练记录
- 存在未结束训练并显示恢复卡片

### 7.2 训练执行页

顶栏固定结构：

- 左侧第一行：“训练时长”辅助文字。
- 左侧第二行：总训练时间。
- 右侧顶部：“训练”页面标签，与“训练时长”同字号和基线。
- 右侧下方：紧凑型“结束”按钮，与总训练时间处于同一视觉行。

“结束”按钮规范：

- 设计稿紧凑尺寸约为 38×20；Flutter 实际可视按钮保持紧凑，但点击区域必须通过透明外层扩展到至少 48×48。
- 文字使用 12 号加粗字，不与页面标签重叠。
- A 使用灰调珊瑚底和白字。
- B 使用盖章红底、墨色描边和轻量硬阴影。
- C 使用操作蓝底和白字。
- 按钮始终可见，不放入更多菜单。

主体：

- 完成组数与总组数
- 整体进度条
- 按动作分组的完整训练组列表
- 计划值、实际值、组选中状态和组计时
- 固定底部次操作与主操作

### 7.3 独立休息页

顶栏复用训练执行页结构，仅将页面标签改为“休息”。

主体：

- 目标休息时长
- 实际休息累计时间
- 距离目标的剩余时间
- 下一组动作、组序号、重量和次数
- 后续一组预览
- 选择其他未完成组
- 结束休息并开始下一组

休息计时：

- A 使用灰调珊瑚进度与雾白底。
- B 使用盖章红进度、墨色描边和纸张底。
- C 使用荧光状态进度和夜幕底。
- 达到目标时只提醒，不自动开始下一组。

### 7.4 设置中的主题切换

设置项名称为“界面风格”。进入后显示三项实时缩略预览：

1. 呼吸节拍，标注“默认”。
2. 训练贴纸册。
3. 夜训仪表。

行为：

- 点击预览后立即切换全局主题。
- 选择结果保存到本地设置。
- 切换主题不重建或清除当前训练状态。
- App 重启后恢复上次选择。
- 用户设置不存在、损坏或值未知时回退到 A。
- 主题切换期间不显示阻塞式加载。

## 8. Flutter 落地架构

使用 Material 3 作为无障碍、导航和基础交互骨架，但不直接采用默认 Material 外观。

建议结构：

- `AppThemeId`：`breathRhythm`、`trainingStickers`、`nightInstrument`。
- 每套主题提供独立 `ThemeData`。
- 自定义 `ThemeExtension` 承载训练状态色、组件形状、硬阴影、计时器和反馈动效参数。
- 页面只读取语义令牌，不读取主题专属十六进制颜色。
- 主题偏好通过本地设置仓储读取和保存。
- 当前训练状态与主题状态相互独立。

语义令牌至少包括：

- `workoutActive`
- `workoutCompleted`
- `workoutSkipped`
- `workoutPending`
- `restProgress`
- `primaryAction`
- `destructiveAction`
- `surfacePrimary`
- `surfaceElevated`
- `outline`
- `timerTextStyle`
- `compactEndButtonStyle`

## 9. 无障碍与适配

- Android 首版以 360–430 逻辑像素宽度为主要验证范围。
- 所有可点击区域至少 48×48 逻辑像素；紧凑视觉按钮通过透明父级扩大点击范围。
- 正文和关键信息的对比度达到 WCAG AA。
- 状态不得只依赖颜色，必须同时提供文字、图标或形状差异。
- 支持系统减少动画设置；启用后移除呼吸、盖章和非必要过渡。
- 支持系统字体缩放，不允许训练时长、休息时间、当前重量和次数被裁切。
- 保持 Android SafeArea，避免与状态栏、导航手势区域重叠。

## 10. 异常与反馈

- 自动保存成功仅显示轻量状态，不弹出阻塞提示。
- 自动保存失败时保留界面数据并提供重试。
- 系统时间异常时暂停异常计时推导，显示明确提示，不展示负数时间。
- 未完成任何组时，“结束”流程不允许生成有效训练记录。
- 放弃训练必须二次确认；主题不能弱化破坏性操作语义。
- 主题资源加载异常时回退到 A，不影响训练数据和当前场次。

## 11. 验收标准

1. 设置中可切换三套完整主题，A 为默认。
2. 主题选择重启后仍保留；未知值回退到 A。
3. 三套主题使用同一页面和组件实现，切换后布局及交互位置不变。
4. A 的主操作色为 `#C76F62`，不再出现原高饱和橙色。
5. 三套主题的今日、训练、休息关键页面符合当前浏览器设计稿。
6. 所有核心 UI 字体使用当前放大后的字号基准。
7. “今日 / 训练 / 休息”标签与左侧顶部辅助文字同基线、同字号。
8. “结束”按钮不遮挡页面标签，可视尺寸紧凑，点击区域不小于 48×48。
9. 训练与休息页始终可见“结束”入口。
10. 主题切换不改变当前训练、组状态、计时或自动保存数据。
11. 字体缩放 1.3 倍时关键训练数据不被裁切。
12. 减少动画开启时，非必要主题动效被禁用。

## 12. 后续实施边界

本规格确认视觉系统和关键页面方向，不要求在一个实施任务内一次完成 PRD 的全部业务功能。Flutter 实施计划应按可独立验证的增量拆分：

1. Flutter 工程骨架、主题系统和设置持久化。
2. 共享基础组件及三套主题预览。
3. 今日首页及其核心状态。
4. 训练执行与休息页面视觉组件。
5. 其余计划、日历、历史、动作库和设置页面。

各增量必须复用同一主题接口，禁止先复制三套页面再事后合并。
